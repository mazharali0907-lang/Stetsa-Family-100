# Stetsa-Family-100
Family 100 adalah permainan interaktif untuk belajar Descriptive Text (appearance &amp; personality). Siswa berkelompok berlomba menebak jawaban berpoin dari kosa kata seperti handsome, tall, kind, hingga funny. Permainan ini membuat kelas lebih aktif, menyenangkan, serta melatih kosa kata dan keberanian siswa.
